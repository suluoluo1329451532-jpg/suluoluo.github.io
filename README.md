# 数字媒体个人作品集网站

这是一个纯静态作品集网站，可以直接部署到 GitHub Pages、Vercel、Netlify 等静态托管平台。

## 替换个人信息

- 在 `index.html` 中替换「你的名字」、邮箱、平台链接、简历链接。
- 在 `script.js` 的 `projects` 数组中替换作品标题、分类、简介、软件、制作内容。
- 把自己的图片或视频放到 `assets` 文件夹，并把 `thumb` 或 `video` 字段改成对应路径。

## 本地预览

直接双击 `index.html` 可以预览。也可以用任意静态服务器打开这个文件夹。

## 部署成可访问链接

推荐做法：

- GitHub Pages：把这个文件夹上传到 GitHub 仓库，在仓库设置里开启 Pages。
- Vercel：导入 GitHub 仓库，选择静态站点部署。
- Netlify：上传整个文件夹或连接 GitHub 仓库部署。

部署完成后，平台会生成一个公开网址。把这个网址发给别人，对方就能访问你的作品集。
